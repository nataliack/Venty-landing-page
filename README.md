# Venty landing page

Promotional launch website for Venty, an app that generates sewing patterns drafted to an individual's exact measurements.

## Stack

- Next.js 15 (App Router), TypeScript, Tailwind CSS 4
- Deployed on Vercel from `main`
- Planned: GSAP + Lenis for scroll motion, React Three Fiber for the 3D hero

## Run locally

```bash
npm install
npm run dev
```

## Media

Masters (the hero video and so on) live in `media/`, the scripts that turn
them into site assets in `tools/`, and the generated assets in `public/`.
See [media/README.md](media/README.md).
